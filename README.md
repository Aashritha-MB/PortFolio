## 📸 Adding Your Photo

1. **Replace the photo file**:
   - Get your professional photo (headshot, passport size, or professional portrait)
   - Rename it to `photo.jpg` (or keep your original name)
   - Place it in the same folder as `index.html`

2. **Update the image source** (if using different filename):
   - Open `index.html`
   - Find line: `<img src="photo.jpg" alt="Aashritha M B" class="profile-photo">`
   - Replace `photo.jpg` with your filename

**Photo Specifications**:
- Size: 280x280 pixels (will be auto-cropped)
- Format: JPG, PNG, or WebP
- Best aspect ratio: Square (1:1)
- File size: Under 500KB
